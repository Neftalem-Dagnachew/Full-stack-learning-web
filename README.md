## 🛠 Tech Stack

| Technology | Purpose |
|------------|----------|
| **React.js** | Frontend UI development and interactive components |
| **Bootstrap CSS** | Modern utility-first styling framework |
| **Node.js** | Backend runtime environment |
| **Express.js** | RESTful API server and routing |
| **MySQL** | Relational database for storing users, courses, and progress |
| **Gemini API** | AI Student Supporter chatbot (explanations, 24/7 support) |
